# TyperPremium Engine ⚡

A high-performance, feature-rich typing speed application built with premium aesthetics and advanced analytics.

## Features
- **Modern UI**: Glassmorphism, dark mode, and smooth CSS transitions.
- **Game Modes**:
    - `Normal`: Classic 60-second test.
    - `Zen`: No pressure, infinite practice.
    - `Hardcore`: Fail instantly on the first mistake.
- **Content Categories**: General English, Coding (JavaScript snippets), and Live Quotes (API-fetched).
- **Advanced Analytics**:
    - WPM & Accuracy tracking.
    - XP & Leveling system.
    - Historical performance charts using Chart.js.
- **Immersive Feedback**:
    - Virtual keyboard with real-time key highlighting.
    - Ghost Mode: Race against your own personal best.
    - Particle effects on successful keystrokes.

## How to Run
Simply open `index.html` in your browser. All stats are saved locally to your browser's `localStorage`.

## Technologies
- HTML5 / CSS3 / JavaScript (Vanilla)
- [Chart.js](https://www.chartjs.org/) for analytics.
- [FontAwesome](https://fontawesome.com/) for icons.
